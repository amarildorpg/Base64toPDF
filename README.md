# 📄 Base64toPDF

Uma ferramenta simples para converter strings Base64 em arquivos PDF. 🛠️

## 📌 Visão Geral

Este projeto consiste em uma ferramenta que permite aos usuários converter strings codificadas em Base64 de volta para arquivos PDF. Isso pode ser útil em cenários onde dados PDF são transmitidos ou armazenados como texto Base64.

## ⚙️ Funcionalidades Principais

* **➡️ Converter Base64 para PDF:** Forneça uma string Base64 válida e obtenha o arquivo PDF correspondente.
* **💾 Salvar Arquivo PDF:** Permite salvar o arquivo PDF decodificado em um local de sua escolha.
* **Interface Simples:** Uma interface de usuário intuitiva para facilitar o processo de conversão. (Dependendo da sua implementação: CLI, GUI, Web)

## 💻 Como Usar

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/amarildorpg/Base64toPDF.git](https://github.com/amarildorpg/Base64toPDF.git)
    ```
2.  **Navegue até o diretório do projeto:**
    ```bash
    cd Base64toPDF
    ```
3.  **▶️ Executar a ferramenta:**
        * Abra o projeto (`.dproj` ou `.dpr`) no Delphi IDE.
        * Compile o projeto (geralmente através do menu `Project` -> `Compile`).
        * Execute o aplicativo (geralmente através do menu `Run` -> `Run` ou pressionando `F9`).
        * A interface gráfica permitirá que você cole a string Base64 e escolha o local para salvar o PDF.
4.  **📝 Utilizando:**
    * Cole a string Base64 na interface ou forneça o arquivo contendo a string (se for CLI).
    * Especifique o local onde deseja salvar o arquivo PDF de saída.
    * Clique em "Converter" ou execute o comando (se for CLI).
    * O arquivo PDF será gerado no local especificado.
